مداد: التطبيق القابل للتثبيت
=============================

هذا المجلد هو التطبيق كاملاً. ترفعه مرة واحدة إلى موقع مجاني، ثم تثبّته على كل أجهزتك.
بعد التثبيت يفتح دون إنترنت، ويزامن نصوصك تلقائياً عند وجود اتصال.

أولاً: مشروع Firebase للمزامنة (مجاني، حوالي ١٠ دقائق، مرة واحدة)
------------------------------------------------------------------
١. افتح console.firebase.google.com وسجّل الدخول بحساب Google.
٢. اضغط «Create a project»، وسمّه مثلاً midad، ويمكنك إيقاف Google Analytics.
٣. من صفحة المشروع اضغط أيقونة الويب </>، وسمّ التطبيق «مداد»، ثم Register app.
   ستظهر كتلة اسمها firebaseConfig: انسخها كلها.
٤. من القائمة: Build › Authentication › Get started › Sign-in method
   فعّل «Email/Password» واحفظ.
٥. من القائمة: Build › Firestore Database › Create database
   اختر أقرب موقع متاح لك، ثم «Start in production mode».
٦. في Firestore افتح تبويب Rules، وامسح الموجود، والصق هذا، ثم Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

٧. افتح الملف config.js في هذا المجلد بأي محرر نصوص، والصق القيم من firebaseConfig
   مكان الفراغات، واحفظ. (أو أرسل الكتلة إلى Claude ليضعها لك.)
   هذه القيم ليست سرية؛ الحماية تأتي من القواعد في الخطوة ٦.

ثانياً: رفع التطبيق إلى الإنترنت (مجاني)
----------------------------------------
١. افتح app.netlify.com/drop
٢. اسحب مجلد midad-app كاملاً وأفلته في الصفحة.
٣. سجّل حساباً مجانياً واضغط «claim» حتى يبقى الموقع منشوراً.
٤. يمكنك تغيير اسم الموقع من Site configuration › Change site name
   ليصبح الرابط مثلاً midad-abdullrhman.netlify.app

ثالثاً: التثبيت على أجهزتك
---------------------------
- iPhone / iPad: افتح الرابط في Safari › زر المشاركة › «إضافة إلى الشاشة الرئيسية».
- Android: افتح الرابط في Chrome › القائمة ⋮ › «تثبيت التطبيق».
- الحاسوب (Chrome أو Edge): أيقونة التثبيت في شريط العنوان، أو زر الحالة في مداد › «ثبّت مداد».
ثم اضغط زر الحالة أعلى التطبيق › «سجّل الدخول».
أول مرة: اكتب بريدك وكلمة مرور جديدة واختر «إنشاء حساب». على باقي الأجهزة: «دخول».

نقل نصوصك من نسخة Claude
-------------------------
في مداد على claude.ai: تصدير › «نسخة احتياطية لكل النصوص».
في التطبيق الجديد: النصوص › «استيراد ملف» واختر الملف.

التحديثات لاحقاً
-----------------
عندما تحصل على نسخة أحدث من المجلد: في Netlify افتح موقعك › Deploys
واسحب المجلد الجديد. ستظهر في التطبيق رسالة «نسخة جديدة جاهزة» فاضغط «حدّث الآن».
(احتفظ بملف config.js الذي عدّلته عند استبدال المجلد.)
